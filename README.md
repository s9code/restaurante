# Restaurante

Proyecto del currículo Full Stack JavaScript de [The Odin Project](https://www.theodinproject.com/).

## 🎯 Objetivo

Construir una página web de un restaurante con navegación por pestañas aplicando:

- Manipulación del DOM para generar dinámicamente el contenido con JavaScript.
- Módulos ES6 para organizar el contenido de Inicio, Menú y Contacto.
- Separación de responsabilidades entre la creación del contenido y la navegación.
- Gestión de eventos para cambiar de pestaña sin recargar la página.
- Uso de npm para gestionar las dependencias del proyecto.
- Configuración de Webpack para empaquetar los módulos y generar los archivos de la web.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
- npm
- Webpack
